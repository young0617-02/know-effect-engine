# 图片、图表与公式：MinerU 本地解析

> 实现状态：DOCX 内嵌图片、独立图片、文本层 PDF 内嵌图片、扫描件/图片型 PDF、PDF 图表区域、PDF 公式六条入口已接通。
> 全部基于项目已有的本地 MinerU/ONNX 能力：**PP-DocLayoutV2 版面 + PP-OCRv6 OCR + SLANet-plus 表格结构 + PP-FormulaNet_plus-M 公式**。
> **不引入额外视觉模型，也不调用外部模型 API**；服务阶段仍只走文本 RAG。

## 1. 边界先说清

| 能力 | 状态 |
|---|---|
| 图片里的文字 | 本地 OCR 后作为普通文本入库、可检索 |
| PDF 图表/插图里的文字 | 版面框内 OCR 后作为「图内文字」入库、可检索 |
| 图表语义（趋势、坐标轴含义、结论） | **不做**；没有视觉描述模型，只保留图内文字 |
| 公式 | 本地 PP-FormulaNet_plus-M ONNX → LaTeX |
| 图片资产 / 原图回链 | **不做**；只存 OCR/LaTeX 文本 |
| 视觉向量检索（CLIP/ColPali） | **不做**；检索仍靠文本嵌入 + BM25 |

一张纯图形、没有文字的图表不会凭空产生可检索内容；这是「不用额外视觉模型」的直接代价，也是本版的明确边界。

## 2. 六条输入入口

| 输入 | 处理方式 | 产出 |
|---|---|---|
| DOCX 内嵌图片 | 解压 `word/media/*` → 本地 OCR | 「图片与图表」章节中的图内文字 |
| 独立图片（png/jpg/jpeg/webp/gif/bmp/tif/tiff） | 单图本地 OCR | 单章节「图片内容」文档 |
| 文本层厚的 PDF 内嵌图片 | pypdf 枚举页面图片 → 本地 OCR | 按页新增 `IMG-<page>` 章节 |
| 扫描件 / 图片型 PDF | `pypdfium2` 渲染整页 → MinerU 版面 + OCR | 正文文字（含扫描页文字） |
| PDF 图表/插图 | 版面模型给 `image/figure/chart` 框 → 框内 OCR | `【图表 第N页】图内文字：...` / `【插图 第N页】...` |
| PDF 公式 | 版面模型给 `display_formula/inline_formula` 框 → PP-FormulaNet_plus-M | `【公式】$...$` |

## 3. 数据流

```
入库（全部本地）
  文档/图片 → MinerU 版面/OCR/表格/公式 → 普通段落
            → Parent-Child 分块 → BGE-M3 嵌入 + BM25 → Milvus

服务（纯文本）
  文本 Query → 混合检索 → 文本 LLM qwen2.5:7b → 引用/拒答/转人工
```

图片 OCR 文本与正文走完全相同的分块、嵌入、权限过滤、复核闸与审计；没有旁路，也没有第二套索引。

## 4. 配置

```dotenv
# 图片/图表 OCR（本地 MinerU/PP-OCR）
KEE_MEDIA_SCAN_TEXT_PDF=true
KEE_MEDIA_MAX_IMAGES_PER_DOC=20
KEE_MEDIA_MIN_IMAGE_PIXELS=1024

# 公式识别（本地 PP-FormulaNet_plus-M ONNX）
KEE_PARSE_FORMULA=true
KEE_FORMULA_MODEL_PATH=
```

- `KEE_MEDIA_SCAN_TEXT_PDF=true`：文本层够厚的 PDF 仍抽内嵌图片做 OCR；关掉后纯文本 PDF 完全不碰图片。
- 图片数量上限与最小像素阈值用于控制图标/装饰图的无效 OCR。
- 公式模型路径为空时使用 `mineru_model_dir/MFR/pp_formulanet_plus_m/PP-FormulaNet_plus-M.onnx`。

## 5. 失败与降级

| 情况 | 行为 |
|---|---|
| OCR 模型不可用 | 跳过该图并写 `parse_notes`；正文照常入库 |
| 图片解码失败（EMF/WMF 等） | 跳过该图，记 note，不拖垮整篇文档 |
| 图片数量超限 | 只处理前 N 张，note 记录总数与处理数 |
| 公式模型缺失/推理失败 | 保留公式区域的 OCR 文本行 |
| 版面模型未判出图表/公式 | 按普通文本行走；可能漏掉图形内文字 |

## 8. 如实边界

- **不做图表语义理解**：只保留图内 OCR 文字；图中没有文字时不会产生描述。
- **不保存原图**：答案不能回链到原图。
- **不做视觉向量检索**。
- **公式准确率未按行业集验收**：复杂分式/矩阵可能出错。
- **已有索引不回填**：这是解析期能力，开启/修改后需重新摄取文档。
- **不支持 xlsx/ppt**；DOCX 里以 OLE 对象嵌入的图表可能只有预览图，OCR 质量受限。
