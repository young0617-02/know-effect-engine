## API 宿主环境要求（ADR-12 定案后必列：API **不在容器里**，这些就是它的部署前提）

- 宿主 Python：`3.12.8`；虚拟环境 `D:\project\know-effect-engine\.venv`
- torch / transformers / sentence-transformers **不在 `pyproject` 依赖里**，由本机 CUDA 底座经 `.pth` 挂载提供（换机必须复刻这一步，否则 API 直接起不来）
- dtype `float16（.env 未覆盖时取 config 默认）`、设备 `cuda（.env 未覆盖时取 config 默认）`：改成 CPU 会打穿 P95 检索门禁，见 `docs/ADR-12_容器化代价实测.md`
- 显存：8GB 要容纳「嵌入 + 重排 +（分时）7B」；同时跑别的 GPU 应用会污染延迟读数
- 端口只绑 127.0.0.1（`serve_api.py` 拒绝非回环绑定）：API 38000、Demo web 38080、Vite dev 38173
- 身份走请求头且**可伪造**，仅内网 Demo 可用；生产必须换真实身份源（《技术方案》7.2.1）
