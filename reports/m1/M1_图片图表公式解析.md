# M1 · 图片、图表与公式解析实测（MinerU-only）

> 日期：2026-10-26｜范围：本地 MinerU 的图片 OCR、图表区域文字、表格结构、公式识别
> 结论：**全部本地完成，不引入额外视觉模型、不调用外部模型 API**。DOCX 内嵌图片、独立图片、PDF 图表框内文字、
> 扫描件 PDF 均产出可检索文字；公式用本地 PP-FormulaNet_plus-M 输出 LaTeX。图表只保留图内文字，不做语义理解。

## 一、实现边界

| 能力 | 结果 |
|---|---|
| 图片里的文字 | 本地 PP-OCRv6 识别后作为普通段落入库 |
| PDF 图表/插图里的文字 | 版面框内 OCR，输出 `【图表 第N页】图内文字：...` |
| 图表趋势/坐标轴含义/结论 | **不做**（没有视觉描述模型） |
| 公式 | 本地 PP-FormulaNet_plus-M ONNX → LaTeX |
| 图片资产/原图回链 | **不做**，只保存文字 |
| 视觉向量检索 | **不做**，仍是文本嵌入 + BM25 |

纯图形、无文字的图表不会产生可检索内容；这是本版最直接的边界。

## 二、实测结果

### 2.1 独立图片（合成季度交付柱状图）

- 入口：`parse_image()` → `MediaPipeline.process_image_bytes()` → 本地 OCR。
- 输出：`【图片 1】图内文字：Quarterly Delivery Amount (10k CNY) Q4: 210 Q3: 180 Q2: 150 Q1: 120`
- note：`独立图片：无固定分页，页码置 0；仅保留图内 OCR 文字`
- 结论：无文字描述，但四个季度数值都进入文本索引。

### 2.2 DOCX 内嵌图片（合成月报图）

- 入口：`parse_docx()` 从 `word/media/image1.png` 抽取 → 本地 OCR。
- 输出：`【图片 1】图内文字：Monthly Defect Trend 42 31 18 9`
- note：`DOCX 内嵌图片：抽取 1 张，处理 1 张，产出文字 1 张`
- 新增章节：`图片与图表`；该段落进入后续 Parent-Child 分块。

### 2.3 PDF 图表区域（合成里程碑柱状图）

- 入口：`parse_pdf()` → MinerU 版面判出 `chart` → 框内 OCR。
- 输出：`【图表 第1页】图内文字：Q4:210 Q3:180 Q2: 150 Q1:120`
- note：`图片/图表区域 1 个：仅保留图内 OCR 文字，不做语义描述`
- 说明：图表框内没有标题文字，标题在框外；OCR 只取框内内容，这是版面裁剪的边界。

### 2.4 扫描件 PDF（`var/m1/fixtures/扫描件_产品安全手册第1页.pdf`）

- 入口：`pypdfium2` 渲染 → MinerU 版面 + OCR。
- 结果：13 个章节、约 **4195 字符**；版面判出 2 个图表区域，保留框内 OCR 文字。
- 结论：扫描页正文与图示文字都可入库；没有视觉描述。

### 2.5 公式 PDF（本地 PP-FormulaNet_plus-M）

- 入口：MinerU 版面判出 `display_formula` → 本地 564MB ONNX 推理，不联网。
- 输入：浏览器 MathML 渲染的二次求根公式。
- 输出（节选）：`\begin{aligned} ... & -b \pm \sqrt{b^2 - 4ac} ... \end{aligned}`
- 结论：公式符号可识别，但分式/对齐结构仍不完美；公式识别失败时保留该区域的 OCR 文本行。
- 去重：同一公式被版面模型输出多个重叠框时，`_dedupe_regions()` 去重为一个。

## 三、数据流

```
入库（全本地）
  文档/图片 → MinerU 版面/OCR/表格/公式 → 普通段落
            → Parent-Child 分块 → BGE-M3 嵌入 + BM25 → Milvus

服务（纯文本）
  文本 Query → 混合检索 → qwen2.5:7b → 引用/拒答/转人工
```

没有第二套图片索引，也没有在线视觉调用；图片 OCR 文本与正文共享权限、复核闸与审计。

## 五、如实边界

1. **不做图表语义理解**：只保留图内文字；图中没有文字时不会产生可检索内容。
2. **公式准确率未按行业集验收**：复杂分式、矩阵、手写公式仍可能出错。
3. **不保存原图**：答案不能回链到原图。
4. **已有索引不回填**：图片/公式是解析期能力，开启后需重新摄取文档。
5. **不支持 xlsx/ppt**；DOCX 的 OLE 图表可能只有预览图，OCR 质量受限。
6. **OCR 仍有字符级错认**：扫描件历史记录中已出现个别中文字符误识；正式使用前需按行业样本评估。
